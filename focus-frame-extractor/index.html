3Sharpness analysis

How the score works

Each frame is converted to grayscale. With “Ignore the static scene” on, a median background is built from about 48 evenly spaced keyframes and subtracted, so fixed edges in the scene (a rail, a ledge, a scale bar) don't count. The Laplacian method then measures the second derivative at every pixel, and the Sobel method measures the edge gradient. A sharp subject produces a few very strong responses and a blurred one produces only weak ones, so the score is the mean of the strongest responses, the top fraction set by “Subject size”. The method only changes which column of scores is used, so you can switch methods after analysis without running it again. Changing the region, subject size or background option needs a new analysis.
